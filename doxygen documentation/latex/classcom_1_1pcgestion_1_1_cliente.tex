\doxysubsection{Detailed Description}
La clase {\ttfamily Cliente} representa a un cliente de la aplicación PCGestión, el cual hereda de {\ttfamily \doxylink{classcom_1_1pcgestion_1_1_usuario}{Usuario}} y tiene funcionalidades específicas como solicitar devoluciones y contratar reparaciones.

Además de los atributos heredados (nombre y email), un cliente tiene una dirección de entrega o contacto.

Ejemplo de uso\+:


\begin{DoxyPre}{\ttfamily \newlineCliente cliente = new Cliente("{}Ana"{}, "{}ana@mail.com"{}, "{}Calle Falsa 123"{});\newlinecliente.solicitarDevolucion(new Producto("{}Mouse"{}));\newline}\end{DoxyPre}
