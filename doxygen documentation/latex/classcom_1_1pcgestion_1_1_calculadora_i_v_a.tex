\doxysubsection{Detailed Description}
La clase {\ttfamily Calculadora\+IVA} proporciona una funcionalidad básica para calcular el precio final de un producto incluyendo el IVA (Impuesto al Valor Agregado).

Actualmente, el valor del IVA está fijado en 21\%.

Ejemplo de uso\+:


\begin{DoxyPre}{\ttfamily \newlineCalculadoraIVA calculadora = new CalculadoraIVA();\newlinedouble precioFinal = calculadora.calcularPrecioConIVA(100.0); // Devuelve 121.0\newline}\end{DoxyPre}
