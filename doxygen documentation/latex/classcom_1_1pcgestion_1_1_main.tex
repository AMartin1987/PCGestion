\doxysubsection{Detailed Description}
La clase {\ttfamily Main} actúa como punto de entrada de la aplicación PCGestión.

Simula un flujo básico de uso de la aplicación\+: creación de un cliente, un producto y una reparación, con interacción entre cliente y técnico.

Ejecuta los siguientes pasos\+:


\begin{DoxyItemize}
\item Creación de un cliente 
\item Creación de un producto 
\item Creación de una reparación 
\item El cliente contrata una reparación 
\item Un técnico acepta la tarea e informa el estado 
\item Se finaliza la reparación 
\item Se imprime el estado final de la reparación 
\end{DoxyItemize}

Este ejemplo permite verificar la interacción entre objetos de distintas clases.
